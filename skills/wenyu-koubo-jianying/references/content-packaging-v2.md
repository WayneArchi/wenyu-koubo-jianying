# 内容包装 v2：判断规则与实现边界

在决定重点、文字角色、图形形式和声音提示时阅读本参考。当前 v2 helper 只实现原生文字包装的一个子集；下列设计建议不代表相应自动化能力已经实现或在剪映通过验证。

## 先找值得剪辑的点

结合表达、语气、具体情境和关键信息判断剪辑点：观众此刻需要看懂什么、感受到什么、记住什么。序数词、总结词、转折词只是候选线索，不能见到“第一”“所以”“重点”就自动放大、弹字或加音效。

参考成片只用于视觉形式、字体候选、颜色与层级；它的主题、时长、删留、顺序及重点分布都不能变成新内容模板。以上内容决定必须由当前原片完整上下文独立支持，忠实概括与逐字引用应明确区分。

新素材先形成内容方案、完整原话稿与主要留删理由，再进入视觉包装。已有明确的直接剪授权时可以连续执行，不额外加一次审批，但仍保留先内容、后视觉的判断记录。本轮已经看过参考，只能记录为参考辅助试做/前向检查，不能当严格盲测；没有隔离参考影响的新素材验证不写盲测通过。

## 按信息任务选形式

| 信息任务 | 可选表达 |
| --- | --- |
| 交代步骤 | 简短步骤标签或序号，让先后关系清楚 |
| 提示当前主题 | 章节标题或位置提示 |
| 比较两个对象 | 并列文字、分栏或其他明确的对比关系 |
| 解释原因和结果 | 因果连接、方向提示或先后出现 |
| 强调一句关键信息 | 短文字、关键词变化或一次克制的运动 |

按实际需要选择一种合适形式，也可以保持原画面。不强制把章节、花字、图形和音效组合使用；避免与口播争夺注意力。

章节标题可以按用户偏好持续到该主题结束；跨视频切点保持同一文字片段，可避免重复弹入。这是工作流建议，不是已从课程核实的普遍规则。是否持续、持续多久、何时退出，都应服从内容和本次约定；不能声称课程要求标题必须留到章节结尾。

## 普通字幕与包装文字分开

普通口播字幕应先由剪映原生语音识别生成，再批量校对、分句和调整样式。执行前核实当前环境具备可用的识别与批量编辑能力。当前文字 helper 未实现这一步；能力未经验证时，明确报告暂不支持，并保留该待办，不能用普通文字轨叠字冒充“剪映识别字幕”。

已有本次范围的有效剪映识别字幕优先复用，只识别缺失范围；核对识别来源及字幕与当前剪口是否对应，不重复全量识别叠轨。原生识别字幕和包装层可以按目标时间线安排先后制作。

识别后必须审错字、过长换行、过短孤立片段和跨主题断句，按语义与实际字体字形宽度合分。操作在右侧“字幕”页逐句列表进行，Return拆段、下一句句首Backspace合并；“文本”页的手动换行不算重分字幕。不能固定字数或逐字均分。操作与本轮各一次实测范围见[原生字幕合分](native-subtitles.md)，操作成立不等于全程同步或字幕质量通过。

章节、步骤和重点文字是另加的包装层。它们不能替代普通字幕，也不宜逐句重复整段口播。分开维护各角色与层级，允许必要的同时出现，同时检查遮挡和阅读负担。

## 本次偏好是配置，不是永久默认

本次用户给出的偏好保存在[样式配置](../config/style-preferences.json)：普通字幕固定白色#FFFFFF，首选新青年体、后现代体备选，字号13号、无描边、阴影65%、高度75%；标题花字也必须采用经确认的非系统默认字体，优先按相同字体顺序尝试。#FFF598仅用于标题/重点花字的常用强调，绝不能套用基础字幕或整条字幕轨。保留可调整的任务配置，不推广为所有项目的固定样式。

剪映界面的“13 号”与 JSON 原生 `size` 的换算尚未核实，不能直接宣称 `size=13` 等于界面 13 号。“高度 75%”也不能直接当成 `transform.y=0.75`；原生位移以半画布为单位，并应实际核对 UI 坐标方向和基准。阴影 65% 对应哪个控件及其映射，应以当前剪映界面为准。

SDK提供的阴影字段和映射仅是序列化依据，尚未由原生UI验证；不能把参数写入成功当成视觉效果达标。字体必须在剪映UI确认真实选中并核对资源；首选缺失可尝试备选并记录，两者均不可用时保留待办、明确报告，不默默用系统默认。不能沿用源码的Windows占位路径，也不能只把字体名写进配置就说已应用。对参照成片只能根据画面辨识字形、粗细等视觉特征，不能声称从扁平MP4恢复了准确font或资源ID。无描边也应在剪映预览确认。最终以原生显示、可编辑性和用户反馈验收字体、字号、阴影与位置。

位置另需[原生安全区验收](native-safe-area.md)。在预览右上“三横”→“安全区”实际查看抖音平台UI与字幕双白框；所有字幕、标题和花字都查，脸与关键动作证据不被平台UI遮挡。外框绝不越，内框尽量不越、少量可接受。不能以猜固定比例或位置参数在范围内冒充已查看，动画峰值和人物移动也要核对。

## 声音与原片

如内容确有需要，可少量使用短音效提示转折、结果或动作，放在独立音轨，便于单独关闭、调整音量和移动。不能见切点就铺音效，也不能用声音掩盖剪辑不顺。当前 v2 未实现音效选择或插入；没有已验证能力时，明确写“暂不支持”，不声称已经加好。自定义图片、图形资产生成和原生字幕识别同样尚未实现。

原始视频文件、原始音频文件和 HLG 属性保持不变。包装修改只作用于获准的新工程与新增层；不附带改写原素材或添加未经要求的调色、HDR 转换及声音处理。

## 遵守本次检查点

用户要求先完成一半再看时，按已约定的视频时间或工作进度检查点停止，提供该阶段可检查的结果和未实现项。不要自行完成后半段，再用“已经做完”代替中途反馈。后续依据用户反馈继续，检查点属于本次协作约定，不自动变成所有项目的强制流程。
