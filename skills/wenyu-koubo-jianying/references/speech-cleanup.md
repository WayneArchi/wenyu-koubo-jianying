# 声音清理：同时处理卡壳和断字

## 两种已出现的失败都不能复制

1. 按 ASR 逐词时间直接裁切、再把入点向后/出点向前取整到视频帧，会吃掉字头字尾。容许“少于一帧的损失”也不能算通过。
2. 为了保护字音恢复整段录音，连重复起句和失败尝试一起保留，只解决连贯，未完成去气口。

最新案例曾用额外的前后保护量减少风险，但没有完整听校；任何固定的 25、35 或 200 毫秒都不是已验证的万能算法。不要照抄单个案例的词索引、时间码、分贝阈值或片段数量。

## 删除什么

| 类型 | 判断 | 操作 |
| --- | --- | --- |
| 重复起句 | 前一遍未完成，后面重新开始且表达完整 | 优先保留完整自然的一遍，删除整个失败尝试，不只删几个字 |
| 自我纠正 | 前一遍表述被后一遍修正 | 保留最终真实意思及其必要上下文，不把两遍都留下 |
| 词内重启 | 如“老—老板”“这这这个” | 找到完整音节/词的实际起点，删除重启；ASR 可能漏记，须听原声 |
| 空转口头词 | “那个”“呃”“嗯”等没有语义或语气贡献 | 有可分离边界才删除；与有效音节连读时优先声音完整 |
| 有意强调 | “一个一个”“该吃吃”“真的差了很多”等具有功能 | 不按重复文本规则删除 |
| 气口/停顿 | 让句子能换气或转折的停顿有功能 | 压缩空转等待，保留必要呼吸和段落节奏 |

所有判断都回到原声，不把这张表当关键词删除列表。

## 如何落刀

1. 先确定删除单位和保留的完整说法，再映射到原片。ASR 原始词级时间戳必须保留，不用均分字幕时长猜每个字的位置。
2. 每个新切点至少带上前后完整句的局部上下文，实际回放；必要时放大波形/声谱，区分辅音、弱读、尾音、呼吸和噪声。
3. 不按“低于多少 dB”直接删声音。安静的辅音仍是有效讲话，呼吸也可能比背景声大。音量和静音检测只能筛候选点。
4. 句前约 0.2 秒作为起始参考，有空间就保留自然吸气；不要把前一个被删除词的尾音一并保留。句尾保留完整韵母及自然收尾。句内连读没有 0.2 秒空间时，不硬造空白。
5. 保留词的区间不能被帧取整向内截掉。若应用只允许帧切，选择能包含完整发音的边界；如会带入另一词，再人工调整删除单元或标待听校，不能靠放宽校验容差掩盖。
6. 不把“向外延长几毫秒”自动判为安全：它可能带入被删词的一部分。记录相邻词侵入，同样需要听校。
7. 检查跳切接缝是否出现残字、点击声、语速突变、连读丢字或过紧。不要用淡入淡出、加速、降噪或静音填补掩盖已裁掉的音节。

## 验证顺序

- 原稿与编辑稿：有没有误删观点、否定、条件或数字。
- 说话人：每段都来自目标人物；身份未明或重叠讲话不得假定已清干净。
- 每个新接点：前后原声和拼接后效果分别听，必要时修改切点；已有人工确认的切点不因机械统一参数重改。
- 从头到尾连续播放：文字稿未显示的重复音节、过密气口、逻辑突兀、视觉跳切是否存在。
- 原生工程：打开、保存后，复核真实源区间与计划一致，没有自动取整造成的截字或漏素材。

没有可用听音工具时，不声称“已经逐句听过”。可以产生标注为待听校的机器粗剪；不能标音频质量通过，也不能让用户的确认替代未做的实际检查记录。用户随后给出问题秒数时，追溯原源位置修该类问题，不只处理一个示例就声称全片清理完毕。
