# 内部计划与验证记录

当前 `audit_plan.py` 只支持恒定 1 倍速片段，目标时长按源区间差计算。读取现有工程时先核对实际速度；片段可显式记 `speed: 1`，省略该字段也只表示 1 倍速。非 1 倍速或变速曲线不得走这个校验器，也不得为了通过检查改回 1 倍速；保留用户原设置并报告需要适配目标时长映射。

这个格式只用于程序校验，不要求用户阅读。每条成片时间线分别有一个计划；目标区间从 0 连续排列，源素材允许调序。所有时间是原始时间轴的整数微秒。用户允许重复使用一段原话时明确记录，不得绕过当前校验器的重复范围拒绝规则；先针对该次真实用例扩展审核，不能静默删去检查。

```json
{
  "sources": [{"id": "source-a", "duration_us": 10000000}],
  "approved": true,
  "approval_reference": "当前对话用户已确认这份完整剪辑稿",
  "speaker_identity_confirmed": true,
  "full_listening_review": false,
  "clips": [{
    "source_id": "source-a",
    "source_start_us": 1200000,
    "source_end_us": 2900000,
    "target_start_us": 0,
    "speaker_status": "confirmed_target",
    "word_intervals": [{"start_us": 1400000, "end_us": 2700000, "text": "完整原话"}]
  }]
}
```

这只是格式示例，不能把示例 approval 或 speaker 状态复制成真实证据。`word_intervals` 必须来自这次原始识别结果或实际校准记录，不能为了通过检查改写时间。说话人状态可以是 `confirmed_target` 或 `single_speaker_confirmed`；单人也先确认素材实际为单人。

只有句级时间时，不按字数均分伪造词区间。复用真实词级结果或实际校准记录；缺少条件则先给无时码内容方案，标精确包装/切点未生成，不用估计字段冒充验证通过。需要新识别时仍受本次授权和避免重复请求的规则约束。

需要追加字幕与重点包装时，为计划增加实际 `canvas.width`、`canvas.height` 正整数；可附 `duration_us`，必须与片段总时长一致。这个附加信息用于包装候选与当前草稿的画幅、时长匹配。只做原有粗剪审计时无需增加字段。

```bash
python3 scripts/audit_plan.py --plan "/absolute/path/plan.json"
```

输出仅表示结构、ASR 区间、授权/身份字段是否齐全。不代表代码核实了用户授权、真人身份或实际听感。`--require-listening` 只检查是否声明完成听校，调用者仍须有真实逐处及连续播放记录；布尔值不能替代执行。

每阶段记录开始/结束、耗时、工具和版本、输入指纹、输出位置、失败/重试、检查范围。不记录密钥或完整请求头。保存身份依据、删减理由、完整稿确认、切点修订及听校范围；内容和音画检查分开标状态。只有复现诊断确实需要时才汇总报告，不为每次剪辑制作长篇工具流水账。

建议稳定工作文件：原始响应、原片阅读稿、当前剪辑稿、内部计划、验证结果。重试复用已成功的步骤；不为安装测试上传真实素材，不把合成测试或历史开发案例当作新视频质量验证。

## 完整成片的补充画面和证据

A-Roll 计划稳定后再建立 B-Roll 清单，每段记录：素材 ID/路径、源入出点、目标入出点、速度、对应口播原话、画面依据、插入作用、原声保留/静音及其理由。源范围和目标时长须按真实帧率与速度核验，不能把另一素材的源时间当成成片时间。另记录配乐独立轨、增益、淡入淡出及具体试听状态。

`audit_plan.py` 仍只审核原有的 1 倍速 A-Roll 计划，不审核 B-Roll、混音、画面语义或真实音节；补充画面的媒体边界与覆盖关系需要另行核对，不能把其通过标记扩展到全片。`build_packaging.py` 也不承担补充画面或配乐写入。

证据分别记录：媒体可解码、时间映射、字幕语义、画面查看范围、原生重开、逐接缝听校、整片连续听看、用户反馈。注明检查对象的版本及修改前后关系；旧导出的检查不能不加说明地沿用为新导出的整片验收。抽帧频率与数量不是理解或试听的证明；用户认可某一案例也不是新素材盲测通过。详细操作日志按需保留在任务目录，不随 Skill 分发私密素材。
