# L02 完整口播实践：已观察到的结果与边界

这是方法来源与案例记录，供理解规则，不是可直接执行的新项目参数表。不包含课程原文、媒体、工程或私密样本。课程演示提供了先精简人物口播、再用补充画面展示所述对象与操作的流程参照；下面的具体数值及检查记录来自这次作业，不作为课程普遍要求。

## 实际制作

- A-Roll 最终选择 3 段、2 个内部接缝，总长 93.5 秒，4K、30 fps。比较并去除失败起句与重复版本，而不是固定每句切一刀；恢复了一处没有必要删除的约 0.433 秒停顿。
- 重录取舍保留了键盘背光这一核心点，但舍弃的前一遍里有“晚上打字会比较难受”的独有例子。因此不能宣称所有独有信息无损保留，后续必须逐版比较，而不是默认选择整段重录就最好。
- 13 个候选补充画面读取了媒体信息，每个看了 3 张抽帧；最终用了 12 段，围绕颜色、键盘、背光、打字、指纹解锁、触控板及代际差异等语义放置。两处跳切均有相应补充画面覆盖，也保留人物表达。候选抽样不等于每个候选都连续看过。所用 B-Roll 没有音轨，不能推广为其他项目一律静音。
- 剪映原生识别最初 54 段字幕，纠错与语义合分后 53 段。处理了专有名词、词内误断及过长表达，而不是按固定字数断行。
- 原生界面确认新青年体；本案例 UI 字号 5、白字、黑色阴影不透明度 90%。位置得到用户认可，但没有可靠记录可推广的高度数值，完整字体资源元数据也未核实。字号及阴影均只用于本项目复现。

## 返修与检查

首轮导出字幕对比不足，随后补阴影；后一轮发现接近满幅的音频采样，再将 A-Roll 降低 3 dB 重新导出。最终技术检查包含全文件解码成功、声道峰值约 -2.95 dBFS 及接近满幅采样数为零。这些指标不证明听感。音乐最终使用过 -32 dB 的输入增益及淡入淡出，但用户认为音乐偏小，不能列为成功混音预设。

第一轮画面按 4 fps 生成并查看 374 张抽帧，阴影返修另看了 14 个关键时点；最后一轮只调整主声音量。这些是对应版本的画面检查记录，不是最终每帧审看。Agent 没有完成真实连续听音，不能事后改写为已经听校。用户随后完整听看，反馈整体非常满意，认可字幕字体、阴影、位置和断行，唯一提出的瑕疵是背景音乐偏小。

## 可复用与不可据此声称的部分

可复用的是完整盘点、重录比较、先稳声音主线、按语义选画面、原生字幕纠错合分、按实际画幅校准、独立音乐轨、分层检查与按反馈返修。不是复制 3 段 A-Roll、12 段 B-Roll、93.5 秒或该项目音量和字号。

这次用户接受是一个案例的结果证据。课程与参照片已经看过，尚不能据此证明陌生素材迁移通过、严格盲测通过、Agent 已完成声音验收或 1～14 课所有操作均熟练。新作业需要独立方案与实际成片验证。
