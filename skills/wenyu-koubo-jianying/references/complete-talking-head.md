# 完整口播成片工作流

用于用户明确要求完整口播成片、补充画面或相应包装的任务。用户仅要粗剪、清理气口或改字幕时只执行授权部分。主 Skill 的原话保护、确认状态、转写服务、工程备份和真实验收约束始终有效；本文件不新增执行工具或自动化接口。

## 1. 先认清本次素材

区分 A-Roll（承载叙事与主声的人物口播）、B-Roll（展示、证明或补充口播的画面）、音乐、参照片和课程演示。素材包只作剪辑候选，不把素材视频当待学习的课程。检查文件可读性、时长、帧率、旋转、画幅、音轨与源范围，原始文件保持不变，工作目录沿用用户指定磁盘。

按当前台词找候选，实际查看画面，不只按文件名或字幕猜。抽帧可筛选候选；包含操作、运动或前后变化时，还须检查所用连续区间。记录查看范围，三张静帧不代表完整看过整段。不存在的素材不编造，不因素材多就全部用上。

复用能核验同源的完整火山结果，保留原始 JSON、全文、段/词时间戳和真实返回的 speaker 字段。用媒体身份、时长与源时间核对同源关系；单凭同名或相似内容不够。不为了本流程或测试规则重新上传、计费。实际服务配置与调用遵循主 Skill。

## 2. 先让 A-Roll 自己成立

完整读原话，建立主线和留删理由，区分完整重录、失败起句、有效补充与自然停顿。对重录版本比较独有信息，不能机械选最后一次；整段选择如果损失独有例子，记录具体取舍，不称无损。按已有用户确认推进，获准直接剪时不再索要同一授权。

先完成可独立听懂的声音主线，再定 B-Roll。源词时间是定位线索，刀口需结合实际发音。逐处检查切点前后的完整话语，保留必要气口；不为了压短时长把每个停顿抹掉，也不用音乐掩盖断字。不能靠叠画面把不自然的声音接缝算作修好。

先保存 A-Roll 源到目标的映射及锁定版本。之后改 A-Roll 长度或顺序，必须同步更新 B-Roll、字幕、音乐及包装位置，旧映射不能继续沿用。只听局部不能写整片听校完成；无法听音时维持待听校状态。

## 3. 让补充画面承担具体任务

每段候选回答：对应哪句原话、画面实际出现了什么、它帮助观众看见什么，以及为什么放在这里。常见作用是展示对象/动作、支撑事实、呈现差异、补足语境、使转场自然；不能只有“更丰富”这一理由。涉及比较，确认画面中的对象、年代或状态确有依据，不靠相似画面冒充证据。

插入起止点服从语义和画面动作。关键动作需看得清，动作未完成不要因为一句字幕结束就截断；过早透露、无关延长或遮住人物重要表情时应调整。人物的提问、判断、态度或转折值得回到 A-Roll；不是一句话必配一段素材，也不是全程用 B-Roll 盖住人物。新项目没有素材时保留人物并列出缺口，不拿课程案例时间表套用。

可用合适 B-Roll 覆盖 A-Roll 跳切，但先确认画面与前后语义成立。保留主声轨的连续性，补充画面放独立可编辑层。检查源入出点、目标入出点、速度和覆盖区间；素材播放速度按内容需求和当前授权决定，不能为填满时长默认慢放。B-Roll 有声音时逐项决定保留、压低或静音，不能照搬无音轨案例一律静音。

## 4. 原生字幕与可读性

A-Roll 稳定后，在剪映对正确时间线与讲话范围识别字幕；识别时隔离音乐及不应识别的声音，完成后恢复原混音。已有有效识别结果优先复用，不叠加重复字幕。识别、纠错和合分的实际操作见[原生字幕](native-subtitles.md)。

先校对专有名词、数字、否定与条件，再按完整语义及实际宽度合分：不把词拆开，不留无意义孤句，也不靠手动换行冒充字幕重分。核对改动后的字音同步，不能只看文字好读。

保留用户认可的新青年体优先、后现代体备选、白色普通字幕与阴影的风格意图。具体字号、位置和阴影强度在当前画幅校准，检查亮/暗背景、最长两行、人物与平台遮挡、动画极值；保存后重开确认。4K 课程案例的 UI 字号不能直接套到竖屏，也不能当 JSON 数值。重点花字与基础字幕分层，仅在帮助理解时增加。

## 5. 配乐放到主声和画面稳定之后

只有当前任务包含配乐时执行。选曲需服从情绪、节奏和语义，不让歌词或突出的旋律妨碍讲话。音乐独立轨，检查起止、循环接缝和所需淡入淡出；不要用黑场、截断音符或突然消失收尾。

输入增益不是最终响度，不把某个负 dB 数值当成所有素材通用标准。先保清晰的人声，再在当前实际听音条件下确认音乐可感知且不抢话；需要时比较有/无音乐与调整前后。检查人声弱句、重句、接缝、音乐强段、开头和结尾，最后整片连续听看。测峰值/削波只能证明对应技术指标，不能证明气口、语义或音乐听感。

本次案例音乐设置过低，用户提出调高；因此不把该值写成成功混音预设。没有实际听音能力时，记录机器检查和待听校项，可按用户明确要求交付待核验预览，但不宣称混音已由 Agent 听校。

## 6. 原生验收、导出与返修

先备份，再以正确草稿/时间线重开核对引用和可编辑层。字幕的真实字体、位置、合分、动画与主声同步独立检查。用户要求导出时，核对画幅、帧率、编码、时长、导出范围与最终文件身份；完成可解码性检查，并按画面变化检查插入/退出、接缝、字幕最长处和关键动作。不能以“导出成功”代替成片验收。

4 fps 抽帧每 0.25 秒检查一次，可用于课程操作定位或成片画面抽查，仍不是逐帧覆盖、动态操作验证或声音验收。记录实际所看版本、抽样频率、范围和遗漏。课程讲解中的操作原因、界面状态、前置条件、参数变化及结果要形成可执行理解，不能把抽完帧叫学会。

验收状态分开写：技术可用、内容与画面核对、接缝听校、整片连续听看、用户接受。缺哪一项就标哪一项，不能互相替代。返修只改反馈对应的层，保留已确认内容；修改长度会联动全部依赖，修改混音须重新检查声音与导出技术指标。只改音量而沿用画面检查时，说明沿用依据，不能称新文件又完整看过。

按用户指定位置交付；iCloud 同步或哈希一致证明副本/传输状态，不证明剪辑质量，也不能把本地复制完成写成另一台设备已能下载。工作素材仍留用户指定的外置磁盘。

## 7. 用新作业检验迁移

[已完成案例](course-practice-case.md)提供经验与边界。迁移检验应换用未照课程剪过的口播及素材，先独立形成删留和 B-Roll 理由，再剪、核对并由用户连续审看。评价语义是否保真、重录是否比较充分、气口是否自然、画面证据是否匹配、字幕是否好读及音乐是否合适；允许插入位置不同，不以课程原片相似度代替验收。未完成该检验前，只称流程已纳入规则，不称通用能力或盲测已通过。
